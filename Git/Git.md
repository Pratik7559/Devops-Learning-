# 🧑‍💻 Git Zero to Hero

## What is Git?

Git is a distributed version control system.

## Git Architecture

-   Working Directory
-   Staging Area
-   Local Repository
-   Remote Repository

## Workflow

Working Directory -\> Staging -\> Commit -\> Push

## Common Commands

``` bash
git init
git clone <url>
git status
git add .
git commit -m "msg"
git log
git diff
git branch
git checkout
git switch
git merge
git rebase
git stash
git tag
git push
git pull
git fetch
git reset
git revert
```

## Best Practices

-   Small commits
-   Meaningful messages
-   Pull before push
